# Map Timeline Tool 技术概览

Map Timeline Tool 是一个用于手动记录点位的轻量 Android 应用。

## 当前技术关注点

- Compose UI 框架与页面
- 领域层 / use case 分层
- Room 持久化
- 使用 osmdroid 渲染地图
- CSV / ZIP / KML / KMZ / GeoJSON 导入导出
- 设置与本地化
- 通知与传感器采集
