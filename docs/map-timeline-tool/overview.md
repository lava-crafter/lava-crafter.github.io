# Map Timeline Tool Technical Overview

Map Timeline Tool is a small Android app for manually logging points.

## Current technical areas

- Compose UI shell and screens
- domain/usecase split
- Room persistence
- map rendering with osmdroid
- CSV/ZIP/KML/KMZ/GeoJSON export-import
- settings and localization
- notifications and sensor capture
