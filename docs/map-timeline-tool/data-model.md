# Data Model

## Point

Core point fields include:

- timestamp
- latitude / longitude
- title
- note
- location accuracy / fix time / provider
- sensor metadata
- noise level
- photo path

## Tags

Points can be associated with tags through a cross-reference table.

## Settings

Settings include map cache policy, zoom button behavior, language preference, and downloaded-area tracking.
